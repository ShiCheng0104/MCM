# 可视化结果说明 (Visualization README)

本目录下的 `outputs/figures` 文件夹包含三个主要的模型解释性可视化系列：

1. **SHAP Summary Plot (Beeswarm)**：用于展示所有特征对模型预测的总体影响方向和强度。
2. **Nomogram (列线图)**：用于将复杂的模型（近似线性化后）转化为可操作的评分卡工具，辅助直观决策。
3. **Residual Case Order Plot (残差个案次序图)**：用于诊断模型预测误差的独立性，检查是否存在时间/顺序上的规律。

## 2. 图像解读指南

### 2.1 SHAP Summary Plot (蜂群图)

这张图展示了特征如何影响模型的预测输出。

- **Y轴**：特征按照重要性从上到下排列。
- **X轴 (SHAP Value)**：表示影响的方向和大小。
  - **正值 (>0)**：表示该特征使预测值增加（正向影响）。
  - **负值 (<0)**：表示该特征使预测值减少（负向影响）。
- **颜色**：表示样本中该特征的数值大小。
  - **红色**：高数值（如 Point Difference 很大）。
  - **蓝色**：低数值（如 Point Difference 小）。
- **解读示例**：
  - 如果一个特征在右侧（SHAP > 0）主要是红色点，说明**该特征数值越高，对结果的正向促进作用越大**。
  - 如果一个特征在左侧（SHAP < 0）主要是红色点，说明**该特征数值越高，反而会降低预测结果**。

### 2.2 Nomogram (列线图)

这是一张可视化的计算图表，用于快速估算模型对特定样本的预测值。

- **结构组成**：
    1. **Points (顶部分数尺)**：一个标准的积分参考尺（0-100）。
    2. **Features (中间特征轴)**：每一行代表一个重要特征。
        - 轴上的刻度对应特征的实际数值。
        - 轴上方的**阴影曲线**（密度图）展示了训练集中该特征数据的分布情况（波峰越高，代表取该值的人越多）。
    3. **Total Points (总分轴)**：位于底部，用于汇总所有特征的得分。
    4. **Linear Predictor (预测值轴)**：位于最底部，将总分映射回最终的预测目标（如评委分数或投票数）。

- **使用方法**：
    1. **查找特征值得分**：在每个特征轴上找到选手的实际数值（例如 `year=2024`）。
    2. **垂直映射**：从该数值垂直向上画一条线，对应到顶部的 **"Points"** 尺，读出该特征的得分（例如 35分）。
    3. **计算总分**：将所有特征的得分相加（例如 $35 + 10 + 20 + ... = 150$ 分）。
    4. **得到预测结果**：在底部的 **"Total Points"** 轴上找到计算出的总分（150），垂直向下画一条线，对应到 **"Linear Predictor"** 轴，读出的数值即为模型预测的分数或投票数。

- **密度曲线的意义**：
  - 特征轴上方的彩色阴影区域展示了数据的分布密度。这有助于直观判断：模型在这个范围内是否有足够的数据支持？某个选手的特征值是否属于常见范围？

### 2.3 Residual Case Order Plot (残差个案次序图)

这张图展示了模型预测误差（残差）随样本观测顺序（通常隐含时间顺序）的变化情况。

- **X轴**：样本的观测序号（Case Order）。由于数据通常按赛季和周次排列，横轴大致对应时间推移。
- **Y轴**：残差（Residuals = 实际值 - 预测值）。
- **参考线**：
  - **虚线 (Zero Mean)**：残差为0的基准线。
  - **实线 (Moving Avg)**：残差的移动平均趋势线。
- **解读方法**：
  - **理想情况**：残差点均匀随机地分布在0线上下，移动平均线平直且接近0。这说明模型已充分提取了数据中的规律，误差是随机的白噪声。
  - **问题信号**：
    - 如果移动平均线有明显的**波动趋势**（如波浪形），说明模型可能遗漏了某些随时间变化的规律（例如某些赛季整体分偏高，或存在周期性波动）。
    - 如果残差分布呈现**漏斗形**（逐渐变大或变小），说明存在异方差性。

## 3. 配色方案

图像采用了一致的专业配色方案（源自 `配色.md`）：

- **背景**：淡灰白色 (`#F8F9FA`)，减少视觉疲劳。
- **主线条/文字**：深青色 (`#264653`)，提供清晰的结构对比。
- **数据/填充**：蓝绿色 (`#2a9d8e`)，用于强调数据分布和密度。
