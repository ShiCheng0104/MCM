# 可视化图表说明文档

本目录包含模型生成的分析图表，各图表说明如下：

## 1. 投票份额雷达图 (Radar Chart)
**文件名示例**: `radar_s20_w5.png`
- **用途**: 展示某一特定周次（如 Season 20, Week 5）中各选手的指标对比。
- **内容**:
  - **Predicted Votes (主色/深蓝绿)**: 模型在无监督情况下反推出的观众投票份额。
  - **Judge Scores (辅助色/青绿)**: 当周评委评分的份额。
  - **Google Trends (强调色/金黄)**: 选手的搜索热度份额。
- **解读**: 如果“Predicted Votes”图形与“Judge Scores”或“Google Trends”图形有显著偏离，说明该选手的存活可能依赖于非评分因素（如极高的观众支持），或者其淘汰是由于某一方面表现极差。

## 2. 预测准确率汇总图 (Accuracy Summary)
**文件名**: `accuracy_summary.png`
- **用途**: 展示模型的整体预测性能。
- **上半部分 (Bar Chart)**:
  - **Overall Accuracy**: 模型预测淘汰者的整体准确率。
  - **Rank Method**: 在使用排名法（Season 1-2, 28-34）赛季的准确率。
  - **Percent Method**: 在使用百分比法（Season 3-27）赛季的准确率。
- **下半部分 (Line Chart)**:
  - 展示准确率随赛季的变化趋势。
  - 背景色块区分了使用**排名法**（Rank Method, 青绿色背景）和**百分比法**（Percent Method, 金黄色背景）的赛季区间。

## 3. 一致性热力图 (Consistency Heatmap)
**文件名**: `consistency_heatmap.png`
- **用途**: 细粒度展示每个赛季、每个周次的预测结果。
- **内容**:
  - **✓ (绿色)**: 预测正确（模型认为被淘汰的人实际上也被淘汰了）。
  - **✗ (红色)**: 预测错误。
  - **空白**: 数据缺失或该周无淘汰发生。
- **解读**: 绿色的连片区域表示模型在这些时期表现稳定；红色的点或区域提示模型在特定赛季（可能是规则变化或特殊事件）失效。

## 4. 不确定性分布图 (Uncertainty Distribution)
**文件名**: `uncertainty_distribution.png`
- **用途**: 分析模型反推结果的可信度。
- **左图 (CV Distribution)**:
  - 变异系数（CV）的直方图。CV越小，表示反推解的范围越窄，结果越确定。
  - 虚线标识了高确定性（CV<0.1）和低确定性（CV>0.3）的阈值。
- **右图 (Certainty Level)**:
  - **High (绿色)**: 确定性高。
  - **Medium (黄色)**: 确定性中等。
  - **Low (红色)**: 确定性低（通常发生在多人分数接近且观众投票空间很大的情况下）。

## 5. 错误分析散点图 (Error Analysis Ranks)
**文件名**: `error_analysis_ranks.png`
- **用途**: 分析预测错误的性质。
- **坐标轴**:
  - **X轴**: 实际被淘汰者的综合排名。
  - **Y轴**: 模型预测被淘汰者的综合排名。
- **对角线**: 理想预测线（实际=预测）。
- **解读**: 点位于对角线上方意味着“实际被淘汰者”比“模型预测的人”表现更好（排名更靠前），这通常是由于未捕捉到的场外因素导致的“爆冷”淘汰。
