# 问题二可视化图表说明

本文档详细说明了 `outputs/figures` 目录下由分析脚本 (`main.py`) 生成的图表含义。这些可视化图表旨在对比 **排名法 (Rank Method)** 和 **百分比法 (Percent Method)** 在结合评委评分和观众投票时的效果差异。

## 1. 投票方法对比概览
**文件名:** `method_comparison_overview.png`

该图提供了两种投票方法在历史所有赛季中一致性的宏观对比。

*   **左图: 一致率 (按赛季) / Agreement Rate**
    *   **柱状高度:** 两种方法（排名法和百分比法）产生完全相同淘汰结果（或底部两名）的周次百分比。
    *   **颜色:** 
        *   **青绿色 (Teal):** 官方赛制使用排名法的赛季。
        *   **深蓝色 (Dark Blue):** 官方赛制使用百分比法的赛季。
    *   **虚线:** 历史平均一致率。
    *   **解读:** 柱子越高，说明方法的选择对该赛季结果影响越小。柱子较低则表明方法的选择显著影响了晋级结果。

*   **右图: 不一致周数 (按赛季) / Inconsistent Weeks**
    *   **柱状高度:** 每个赛季中两种方法产生不同结果的具体周数。
    *   **解读:** 突出显示了哪些赛季最容易因赛制产生"争议"或结果偏差。

## 2. 争议案例研究 - 排名轨迹
**文件名:** `controversy_trajectories.png`

这张组合图（2x2网格）展示了四位历史上著名的争议选手：**Jerry Rice (S2), Billy Ray Cyrus (S4), Bristol Palin (S11), 和 Bobby Bones (S27)** 的每周表现轨迹。

*   **X轴:** 比赛周次。
*   **Y轴:** 排名 (1为最高/最好)。
*   **线条说明:**
    *   🔴 **评委排名 (红/Red):** 仅根据评委评分得出的排名。（对于争议选手通常较低/较差）。
    *   🟡 **观众排名 (黄/Yellow):** 仅根据估计的观众投票得出的排名。（通常很高/很好）。
    *   🟢 **综合 - 排名法 (青/Teal):** 使用50/50排名法计算的综合排名。
    *   🔵 **综合 - 百分比法 (深蓝/Dark Blue):** 使用50/50百分比法计算的综合排名。
*   **解读:** 红色和黄色线条之间的巨大垂直差距表明了"两极分化"的表现。您可以观察青色和深蓝色线条如何在这些极端之间进行权衡。

## 3. 分歧热力图
**文件名:** `controversy_heatmap_comparison.png`

该热力图通过量化评委和粉丝对争议案例的认知差距，解释了结果产生分歧的根本原因。

*   **左图: 排名差异 / Rank Discrepancy (评委排名 - 观众排名)**
    *   **指标:** 正值表示观众给出的排名比评委**更好**（数值更小）。
        *   *计算公式:* `Gap = 评委排名 - 观众排名`
        *   *示例:* 评委排第10 vs 观众排第1 = 差距为 +9。
    *   **颜色:**
        *   **青绿/Teal (+):** 观众比评委更喜欢该选手（粉丝拯救）。
        *   **红/Red (-):** 评委比观众更喜欢该选手。
    
*   **右图: 份额差异 / Share Discrepancy (观众% - 评委%)**
    *   **指标:** 总池中的*百分比份额*差异。
        *   *计算公式:* `Gap = 观众投票份额% - 评委得分份额%`
    *   **颜色:** 解释同上（绿色 = 粉丝偏爱，红色 = 评委偏爱）。
    *   **解读:** 此图解释了**百分比法**为何有效或失效。巨大的份额差距（青色区域）往往能解释为什么百分比法会拯救一个得分很低的选手（如果他们在观众投票份额中占据压倒性优势）。

## 4. 单一案例深度聚焦: Bobby Bones
**文件名:** `bobby_bones_trajectory.png`

一张单独的、高分辨率的轨迹图，专门展示 **Bobby Bones (第27季)**，他是节目历史上最具争议的冠军之一。

*   **视觉元素:** 与 `controversy_trajectories.png` 相同，但细节更丰富。
*   **核心看点:** 观察 **评委排名 (红)** 如何持续停留在底部，而 **观众排名 (黄)** 始终保持在顶部。**排名法 (青)** 和 **百分比法 (蓝)** 的线条展示了不同的数学机制如何让他在低分情况下依然一路晋级至夺冠。
